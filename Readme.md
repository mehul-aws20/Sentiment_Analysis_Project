# Sentiment Analysis using Bag of Words (BoW) and TF-IDF

## Project Overview

This project performs sentiment analysis on text reviews using Natural Language Processing (NLP) techniques. Two feature extraction methods, Bag of Words (BoW) and TF-IDF, are used to convert text into numerical features. A Multinomial Naive Bayes classifier is then trained to classify reviews as positive or negative.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Jupyter Notebook

## Methodology

1. Data Preprocessing
2. Train-Test Split
3. Feature Extraction using:

   * Bag of Words (CountVectorizer)
   * TF-IDF (TfidfVectorizer)
4. Model Training using Multinomial Naive Bayes
5. Performance Evaluation

## Results

| Model              | Accuracy |
| ------------------ | -------- |
| Bag of Words (BoW) | 89%      |
| TF-IDF             | 58%      |

## Conclusion

The Bag of Words model achieved higher accuracy than the TF-IDF model on the given dataset. The project demonstrates the application of NLP techniques for sentiment classification and highlights the impact of feature extraction methods on model performance.
